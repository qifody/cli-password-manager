# CLI Password Manager

Небольшой консольный менеджер паролей, написанный на Python.
Проект сделан в учебных целях - чтобы разобраться, как на практике работают базовые вещи из криптографии:
KDF, salt, симметричное шифрование и безопасное хранение данных.

Все пароли хранятся в зашифрованном виде в локальном файле vault.
Для доступа используется мастер-пароль.

## Возможности

* создание и открытие vault
* добавление записей (сервис / логин / пароль)
* просмотр сохранённых записей
* удаление записей
* генерация случайных паролей
* автоматическая блокировка vault после периода неактивности

## Как это работает

При создании vault пользователь задаёт мастер-пароль.

Далее:

1. Генерируется случайная соль (salt)
2. Мастер-пароль и соль проходят через PBKDF2
3. Полученный ключ используется для шифрования данных
4. Все записи хранятся в зашифрованном виде в файле vault.json

Для шифрования используется алгоритм AES-GCM.

Мастер-пароль нигде не сохраняется - при открытии vault ключ каждый раз заново вычисляется через PBKDF2.

## Структура проекта

crypto/ - функции шифрования и генерации паролей
storage/ - работа с файлом vault
manager/ - управление записями
main.py - основной CLI интерфейс

## Запуск

Требуется Python 3.10+

Установить зависимости:

pip install -r requirements.txt

Запустить программу:

python main.py

## Для чего этот проект

Этот проект не является полноценным production password manager.
Он сделан как учебная практика для изучения:

* криптографических примитивов
* архитектуры небольших проектов
* безопасного хранения данных
